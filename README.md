# Customer Shopping Behavior Analysis

## Overview

This project analyzes customer shopping behavior using Python, SQL, and Power BI to identify purchasing trends, revenue patterns, customer segmentation, and business insights.

---

## Technologies Used

* Python
* Pandas
* NumPy
* SQL
* Power BI
* Matplotlib
* Seaborn

---

## Key Features

* Data Cleaning & Preprocessing
* Exploratory Data Analysis (EDA)
* Revenue Analysis
* Customer Segmentation
* Discount Impact Analysis
* Interactive Power BI Dashboard

---

## Key Insights

* High-performing product categories were identified
* Loyal customers contributed major revenue
* Discounts influenced purchasing behavior
* Customer segments showed different buying patterns
